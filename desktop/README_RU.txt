Версия 0.7.0 — RedReaderStudio

Настройки организованы во вкладки, голоса находятся в «Режим проекта / ИИ».
Удаление переносов строк и абзацев из готовых фрагментов включено по умолчанию.
Это не мешает учитывать абзацы при делении. Сохранённые настройки старых проектов не сбрасываются.

При создании проекта и импорте предлагается распределить роли с помощью ИИ.
Сначала размечаются роли главы, затем каждая реплика делится под длину фрагмента.
Персонажи используют постоянные ID. Имена, пол, ФИО, прозвища, происхождение и обращения
можно изменить в контекстном меню проекта/главы → «Свойства проекта / раздела».
Неизвестные персонажи нумеруются. ИИ может ошибаться: проверяйте сведения и назначения.
Новые проекты находятся рядом с программой в projects/, все образцы копируются внутрь проекта.
Папка voices/ рядом с программой необязательна: WAV/FLAC/MP3, рядом JSON с description и reference_text.
Без библиотеки у персонажей нет назначенных голосов. При генерации применяется голос по умолчанию с уведомлением.

В «Настройка» можно задать автозамены и перетащить этапы обработки.
Распределение ролей должно находиться раньше деления на фрагменты.
Удаление кавычек до анализа ролей может снизить точность определения говорящего.
После замены, увеличившей текст, максимальная длина фрагмента проверяется повторно.
Изменения обработки текста применяются при новом импорте/пересборке; уже готовое аудио не меняется.
Параметры голоса и генерации применяются со следующего фрагмента текущей очереди.

По умолчанию: 10 повторов при ошибках и 10 повторов при сверке ниже 85%.
После исчерпания повторов очередь продолжается. Сохраняется лучшая сверка и WAV каждой успешной попытки.
Если все попытки дали ошибку, фрагмент отмечается ошибкой; его можно выделить и повторить позже.
Ошибка распознавания не удаляет сгенерированный WAV.

У внутренних пауз сохраняются защитные края по 300 мс.
Начальная пауза удаляется, если больше 800 мс, с запасами 50 мс от начала и 200 мс от конца.
Конечная пауза удаляется, если больше 800 мс, с запасами 200 мс от начала и 50 мс от конца.
Каждая функция отключается отдельно, пороги и запасы изменяются во вкладке «Паузы».
Можно установить порог 500 мс. Удаление обратимо: исходный WAV сохраняется.

Higgs Reader Studio 0.6.0 — новая версия

НОВОЕ В 0.6.0
• Экспорт готовых разделов доступен во время генерации. Экспорт использует
  снимок сохранённых аудиофайлов на момент запуска. Очередь продолжает работу.
• «Голос и настройки» доступно во время генерации. Текущий фрагмент завершается
  с прежними параметрами; новые применяются со следующего фрагмента.
  После сохранения показывается уведомление. Разбиение уже созданных
  фрагментов не меняется без команды пересборки.
• Генерация одного раздела автоматически продолжается по следующим разделам
  проекта (в порядке дерева), пропуская готовое аудио. Это можно отключить в
  «Голос и настройки». При выборе нескольких разделов генерируется только выбор.
• «Режим проекта / ИИ»: простой/расширенный режим, исправление текста,
  распределение реплик, анализ персонажей всей книги с сохранением прогресса.
  Переключение режима сохраняет исходный текст, аудио и результаты анализа.
• Настраиваемые голоса персонажей: описание, модель, образец и его текст.
  Результаты ИИ можно посмотреть; выбранные реплики и назначения — исправить.
  После изменения реплик нажмите «Перегенерировать выбранные».
• «Модели / API»: каталог с фоновой загрузкой и локальный HTTP API.
  Подробные методы и примеры находятся в API_RU.md.
• В комплекте дополнительно: Piper Денис/Дмитрий, Qwen 2.5 1.5B и 3B.
  Все включённые модели работают без сети. Дополнительные модели скачиваются
  по запросу, это единственная функция, которой требуется интернет.
• Ctrl + колёсико меняет масштаб дорожек вокруг указателя мыши.
  Вверху дорожек есть временная линейка исходной записи.
• Отключённую паузу можно сдвинуть: Alt + перетаскивание или
  правая кнопка → «Сместить паузу…» (точное смещение в миллисекундах).
  Пауза не пересекает другие отключённые части и удалённые промежутки.
• Паузы длиннее порога можно заменять тишиной заданной длительности в мс.
  Оригинал сохраняется и восстанавливается через меню дорожки.
• При нехватке свободной видеопамяти языковая модель использует CPU.

Higgs Reader Studio 0.6.0 — Windows x64

ЗАПУСК
Дважды нажмите HiggsReader.exe. Устанавливать Python, Flutter, FFmpeg или
скачивать модели не требуется. Переносите всю папку 0.6.0 целиком.
Программа работает без интернета. Windows 10/11 x64.

ПРОЕКТЫ
Новый проект создаёт отдельную папку. В неё автоматически записываются
project.json, audio/ с версиями WAV, voices/ с эталоном и preview.wav.
Чтобы открыть сохранённую работу, выберите project.json.
Дерево позволяет создавать разделы любой вложенности. Можно работать
прямо в корне. Текст раздела идёт перед текстом его дочерних разделов.
Фрагменты можно переносить между разделами.
Счётчики каждого узла: всего / сгенерировано / подтверждено вручную;
учитываются все вложенные разделы. Правой кнопкой по дереву можно
дублировать, переименовать, добавить раздел, пересобрать текст, экспортировать
ZIP или аудио, продолжить генерацию и удалить проект/раздел.
ZIP включает структуру, текущие записи, их версии и используемый эталон.
Распакуйте ZIP в отдельную папку и откройте project.json.
Удалённый проект переносится в .reader-trash рядом с прежней папкой.
Проекты 0.2.0 открываются автоматически; перед обновлением сохраняется
резервная копия project-v0.2.0.backup.json.

ФОНОВЫЙ ИМПОРТ БОЛЬШИХ КНИГ
Чтение, анализ структуры и разбиение документа выполняются в отдельном
потоке. Внизу окна — стадия операции, мини-прогресс и «Отменить импорт».
Если количество работы ещё неизвестно, индикатор движется без процентов.
Запрос разделения на главы не блокирует работу основного окна.
Разделы появляются постепенно. Можно выбрать уже добавленную главу
и запустить генерацию, пока остальной документ продолжает загружаться.
Очередь озвучивает фрагменты, доступные на момент её запуска; новые главы
можно запустить следующей очередью. Прогресс импорта и генерации независимы.
Отмена оставляет уже добавленные фрагменты. Повторный импорт заново
добавляет документ, поэтому для полного повторного запуска используйте
пустой раздел. Одновременно выполняется один импорт; смена или удаление
проекта доступны после его завершения либо отмены.
Автосохранение выполняется в фоне. Ошибки записи отображаются в окне.
Таблица и дорожка показывают по 300 фрагментов; кнопки «Назад / Далее»
переключают страницы. Генерация, проигрывание раздела и полный экспорт
обрабатывают весь выбранный раздел, независимо от открытой страницы.
Выделение сохраняется при переходе между страницами; Ctrl/Shift добавляют
фрагменты на текущей странице. «Снять выделение» очищает весь выбор.

РАЗБИЕНИЕ И ОЧИСТКА ТЕКСТА
В новых проектах лимит — 300 символов. В существующих проектах ранее
сохранённый лимит остаётся; изменить его можно в «Голос и настройки».
Приоритеты по умолчанию: абзац → точка → запятая → отключить.
Каждый из четырёх списков позволяет выбрать абзац, точку, запятую,
пробел или отключение этого приоритета. Повторные приоритеты учитываются
один раз. Точка включает также !, ? и многоточие.
Алгоритм заполняет фрагмент целыми предложениями. Следующее предложение,
которое не помещается в остаток, переносится целиком в новый фрагмент.
Предложение длиннее лимита начинается в новом фрагменте и делится
по максимально возможным запятым. Если подходящих границ нет, применяется
жёсткий лимит символов, чтобы текст всегда мог быть озвучен.
Удаление переносов строк выключено по умолчанию. При включении строки
соединяются пробелом ДО разбиения; границы абзацев тогда исчезают.
Двойные пробелы и двойные переводы строки удаляются попарно за заданное
число циклов; по умолчанию по 3, 0 отключает соответствующую очистку.
Например, 16 пробелов после трёх циклов превращаются в 2 пробела.
Настройки общие для проекта и доступны также в окне экспорта.
При импорте/пересборке обрабатывается исходный текст. При экспорте
очищается встроенный текст аудиофайла. Экспорт не пересоздаёт готовые WAV:
для нового деления используйте «Пересобрать…», затем генерацию.
Над редактором справа отображается актуальное число символов.

ГРУППОВЫЕ ДЕЙСТВИЯ С РАЗДЕЛАМИ
В дереве Ctrl выбирает отдельные разделы, Shift — диапазон. Правой кнопкой
по выделению: дублировать, пересобрать фрагменты, экспортировать в одно
аудио, продолжить генерацию или удалить. Включаются вложенные разделы;
одновременное выделение родителя и потомка не дублирует содержимое.
Порядок генерации и объединения соответствует порядку дерева.

СИМВОЛЫ И МОНТАЖ АУДИО
В настройках текста есть «Удалять лишние символы» и строка списка.
Элементы разделяются ; без пробелов вокруг разделителя. Сам символ ;
записывается как ^;, символ ^ — как ^^. Например: «;»;^; удаляет кавычки
и точку с запятой. Галочка по умолчанию выключена, список пуст.

В «Голос и настройки» можно включить автоматическое исключение пауз
длиннее заданного числа миллисекунд. По умолчанию включено, порог 1000 мс.
Проверяется сгенерированный WAV; исходный файл остаётся в проекте.
Паузы показываются серыми неактивными частями внутри текстового фрагмента.
Воспроизведение, общая запись и экспорт используют активное аудио и заданную
заменяющую тишину. Отключённые исходные паузы в результат не входят.
Поиск тишины использует порог около −48 dBFS и шаг 10 мс; у границ пауз
сохраняются 40 мс, чтобы не обрезать переходы речи. Тихая речь может быть
похожа на паузу — исключённые части всегда можно включить обратно.

Правой кнопкой на дорожке: отключить/включить часть, удалить часть,
найти и разделить паузу, разъединить по курсору, объединить выбранные
части, отменить изменение или восстановить исходное аудио.
Для ручного монтажа включите «Выделение аудио мышью». Ctrl/Shift выбирают
части внутри одной исходной записи; протягивание мышью выделяет диапазон.
Правой кнопкой по диапазону → «Удалить выделенную область».
Масштаб 1×–20× позволяет точнее выбрать границы. Без режима выделения
мышь управляет воспроизведением, как в предыдущей версии.
Объединение доступно для соседних частей одинаковой активности без
удалённого промежутка. Монтаж не объединяет разные текстовые фрагменты.
Удаление логическое: оригинал остаётся. До 100 действий можно отменить,
а весь оригинал восстановить независимо от глубины истории. Повторная
генерация сохраняет прежнее аудио и монтаж в «Версии».
Ручной монтаж не меняет исходный текст и помечает запись для проверки.
Исходный WAV, части и история включаются в ZIP проекта.

ТЕКСТ И ДОРОЖКА
Поддерживаются TXT, MD, DOCX, PDF с текстовым слоем, EPUB, HTML и RTF.
Импорт добавляет текст в выбранный раздел и делит его по предложениям.
Если выбранный раздел с потомками пуст, найденные заголовки DOCX, EPUB,
HTML/Markdown или названия глав в тексте можно импортировать как дерево
вложенных разделов. Программа предложит этот вариант перед импортом.
Лимит длины новых фрагментов задаётся в настройках (20–2400 символов).
Текст во встроенном редакторе сохраняется автоматически; есть также кнопка
«Сохранить текст». Изменение текста делает старое аудио неактуальным,
сохраняет его в истории и требует новой генерации.
Для ручного разделения поставьте курсор и нажмите «Разделить по курсору».
Ctrl выбирает отдельные строки, Shift — диапазон; затем можно
перегенерировать или перенести выбранные фрагменты.
Правой кнопкой по выделению: удалить, пересобрать под установленную
длину, экспортировать аудио или сгенерировать выбранные записи.
Пересборка объединяет соседние выбранные фрагменты внутри каждого раздела
и делит их заново; старые записи остаются в папке проекта.
На дорожке показаны реальные волны готовых WAV и соответствующий текст.
Во время воспроизведения показано текущее распознанное слово.
При проигрывании раздела ползунок времени перематывает весь раздел,
включая переходы между файлами. На дорожке можно щёлкнуть по другому
озвученному фрагменту или перетащить указатель воспроизведения.
Перемотка на паузе сохраняет паузу. Ctrl/Shift служат выделению и не
перематывают звук. При переходе к фрагменту на другой странице нужная
страница дорожки открывается автоматически. Щелчок во время паузы между
фрагментами на общей шкале переводит к началу следующей записи.

ГЕНЕРАЦИЯ И ПРОВЕРКА
Higgs Audio 4B — исходный генеративный движок, с эталоном голоса или без.
Для GPU рекомендуется NVIDIA с 16 ГБ VRAM, из них свободно около 10–12 ГБ.
При нехватке свободной видеопамяти включается экономный 4-битный режим.
При отсутствии CUDA используется CPU, что существенно медленнее.
Для быстрой русской озвучки на CPU по умолчанию выбран голос «Ирина».
Модель Higgs ориентирована прежде всего на английскую речь.

Каждый WAV распознаётся локальной Whisper small, затем нормализованные
слова сверяются с исходником. Пропуски, замены и лишние слова отмечаются.
При расхождении фрагмент помечается для прослушивания, но очередь
продолжает работать. Ручное подтверждение не требуется для генерации
следующих фрагментов и экспорта; оно служит вашей отметкой проверки.
Распознавание не даёт абсолютной гарантии полноты: оно может ошибаться
на именах, ударениях, числах и терминах. Статус показывает результат
автоматической сверки или ручное подтверждение, а не гарантию качества.

Кнопка «Остановить» завершает текущий фрагмент и его проверку, сохраняет
результат и останавливает очередь. «Продолжить очередь» выполняет оставшиеся
элементы последней очереди, включая выборочную перегенерацию.
Для оставшихся элементов используются текущие настройки голоса; уже
сгенерированные записи сохраняются без изменения.
«Генерировать / продолжить раздел» обрабатывает все неготовые фрагменты
выбранного раздела и его потомков. Любые готовые записи пропускаются,
включая ожидающие прослушивания.
После сбоя или перезапуска незаконченный фрагмент генерируется заново,
а завершённые остаются. Одновременное редактирование проекта из двух
окон блокируется. При работе очереди текст и структура не редактируются.

ЭКСПОРТ
preview.wav обновляется после каждого сгенерированного фрагмента. Это
промежуточная запись: в ней могут отсутствовать ещё неготовые фрагменты
и присутствовать записи, ожидающие проверки. После правок используйте
финальный экспорт, который заново собирает актуальные версии.
«Экспорт аудио» объединяет текущий раздел и всё его вложенное содержимое.
В окне сохранения автоматически предлагается имя вида
«Проект — Раздел — Подраздел.wav». Его можно изменить перед экспортом.
Аналогичные имена используются для ZIP и отдельных файлов разделов.
Недопустимые для Windows символы заменяются подчёркиваниями; слишком
длинные названия сокращаются с сохранением уровней дерева.
Для всей книги выберите корень; для отдельной сцены — нужный подраздел.
Форматы: WAV, MP3, FLAC, M4A, M4B. При отсутствии части аудио можно
догенерировать недостающие фрагменты и автоматически экспортировать
результат либо пропустить несгенерированные. Подтверждение не требуется.
Если готового аудио нет, файл не создаётся. Запись экспорта выполняется
через временный файл: ошибка не обнулит ранее сохранённый результат.
В диалоге экспорта можно добавить обложку PNG/JPEG и текст именно тех
фрагментов, которые вошли в аудио. Теги доступны для MP3, FLAC, M4A/M4B
и обычного WAV (ID3); RF64 — без тегов. Их отображение зависит от плеера.
«Экспорт по разделам» создаёт по WAV для каждого раздела дерева, включая
его вложенные разделы; поэтому содержимое дочернего раздела также входит
в файл родительского. Пауза между фрагментами задаётся в настройках.
Формат исходных фрагментов: моно PCM 16-bit, 24 кГц.
M4B не содержит метаданные глав. Для WAV больше 4 ГБ автоматически
используется расширение RF64; встроенный конвертер его поддерживает.

ФАЙЛЫ И ДИАГНОСТИКА
Предыдущие записи не удаляются. Кнопка «Версии» восстанавливает текст
и WAV выбранной старой версии. Для резервной копии скопируйте проект.
Логи запуска: logs/reader.log. Модели: models/. Зависимости: runtime/.
Piper копирует встроенные данные espeak в локальную временную папку,
если путь программы содержит кириллицу; интернет для этого не нужен.
