# RedReaderStudio

Windows-приложение для локальной озвучки книг и документов, редактирования дорожек и распределения реплик между персонажами.

Версия 0.7.0. Готовая portable-сборка включает Python, движки, проверку Whisper, языковые модели, FFmpeg и зависимости. После распаковки интернет и установка Python не нужны. Запуск: `RedReaderStudio.exe`. Проекты находятся в `projects/` рядом с программой; образцы голосов и аудио хранятся внутри каждого проекта.

## Возможности

- Вложенные проекты/главы, фоновый импорт TXT, MD, DOCX, EPUB, PDF, HTML, RTF с постепенным появлением разделов.
- Фрагментация по 300 символов, приоритеты абзац/предложение/запятая/пробел, автозамены и порядок обработки.
- Удаление абзацев из готовых фрагментов включено по умолчанию. Приоритет абзаца работает до удаления переносов.
- Расширенный режим: коррекция текста и распределение ролей до финального деления. Постоянные ID персонажей, пол, ФИО, происхождение, прозвища и обращения; свойства проекта и глав.
- Голос по умолчанию и профили голосов в «Режим проекта / ИИ». Папка `voices/` может содержать WAV/FLAC/MP3 и одноимённые JSON с `description` и `reference_text`. Образцы копируются внутрь проекта. Без библиотеки роли остаются без назначенного голоса; при озвучке используется голос по умолчанию с уведомлением.
- До 10 повторов при ошибке и до 10 повторов при сверке ниже 85%. Сохраняется лучший вариант; после исчерпания попыток очередь продолжается.
- Обратимое исключение пауз, защитные края по 300 мс, ручное редактирование и перемещение отключённой паузы, масштаб Ctrl+колесо и временная шкала.
- Экспорт WAV/MP3/FLAC/M4A/M4B во время генерации, обложка и текст для поддерживаемых форматов, ZIP проекта.
- Локальный API с авторизацией Bearer: задания любой длины, модели, загрузки, простой/расширенный режимы и диалоги. См. [документацию API](desktop/API_RU.md).

ИИ может ошибаться в определении говорящего, связях между именами и исправлениях. Свойства персонажей редактируются пользователем; оригинал импортированного текста сохраняется в проекте. Переключение в простой режим сохраняет сведения о персонажах.

## Portable-релиз

Скачайте все части одного релиза и `Extract-RedReaderStudio.ps1` в одну папку. Запустите скрипт через PowerShell: он проверяет SHA-256, объединяет части и распаковывает программу штатными средствами Windows. Дополнительный архиватор не нужен. Локальная сборка в рабочем проекте уже распакована в `release/0.7.0/`.

## Разработка

Исходники приложения: `desktop/`. Сборка Windows: `scripts/build_release.ps1` (требует подготовленный `release/0.7.0/runtime` и `models` из portable-пакета). Зависимости зафиксированы в `desktop/requirements-lock.txt`. Тесты: `runtime/python.exe -m pytest desktop -q`. Старые прототипы web/backend не входят в настольный интерфейс.

Модели и runtime не хранятся в Git; они входят в portable-релиз. Пользовательские книги, проекты, образцы и токены не включены в репозиторий.
